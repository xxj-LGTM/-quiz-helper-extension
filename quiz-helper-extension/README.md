# 题目助手 · 网页识题解题插件

一个 Chrome / Edge 浏览器扩展：识别网页上的题目（文字题、选择题、图片题），调用**免费大模型接口**给出答案和解析。

- **默认免 Key**：装好就能用，不需要注册账号、不需要填 API Key
- 想更稳 / 要「截图识题」时，再换成自己的免费 Key（智谱 `glm-4v-flash` 免费且支持读图）
- 纯前端，无后端；Key 只存浏览器本地，不上传任何服务器

---

## 一、安装（推荐：一键脚本）

双击 **`install-to-browser.cmd`**，它会自动完成：

1. 把插件复制到固定目录 `C:\Users\Public\QuizHelper\extension`（以后移动本文件夹也不影响）
2. 在桌面创建快捷方式 **「题目助手 Edge」**
3. 启动 Edge 并加载插件

之后**请用桌面的「题目助手 Edge」启动浏览器**（普通 Edge 图标不带插件）。

> 注意：Edge 已经开着时命令行参数不生效，脚本会提示你先完全退出 Edge 再双击桌面快捷方式。

### 手动安装（想装成常驻扩展）

1. 复制插件到固定目录：
   `robocopy "本目录\quiz-helper-extension" "C:\Users\Public\QuizHelper\extension" /E`
2. 浏览器打开 `edge://extensions`（Chrome 是 `chrome://extensions`）
3. 右下角开启 **开发人员模式**
4. 点 **加载解压缩的扩展** → 选择 `C:\Users\Public\QuizHelper\extension`

装好之后用正常的 Edge 图标就行，不必再用快捷方式。

## 二、开箱即用的免 Key 模式（默认）

默认走一个公共免费接口（Pollinations，`text.pollinations.ai`），**不需要 Key**：

- 限制 1：同一 IP 大约 **45 秒只能问一次**，问快了会提示「免费接口限速」
- 限制 2：**只支持文字题**，不能读图（点「截图识题」会提示你换模型）

要解除这两个限制，按第三节换成自己的免费 Key，一分钟搞定。

## 三、换成自己的免费 Key（推荐长期用）

设置页内置 5 个预设，选服务商 → 粘贴 Key → **测试连接** → 保存：

| 服务商 | 免费情况 | 推荐模型 | 支持读图 |
|---|---|---|---|
| **智谱 GLM**（首选） | `glm-4v-flash` 免费 | `glm-4v-flash` | ✅ |
| 硅基流动 | 有免费模型，视觉模型按量计费极便宜 | `Qwen/Qwen2.5-VL-7B-Instruct` | ✅ |
| 魔搭 ModelScope | 每日免费额度 | `Qwen/Qwen2.5-VL-72B-Instruct` | ✅ |
| Google Gemini | 免费额度（需能访问 Google） | `gemini-2.5-flash` | ✅ |
| OpenRouter | 带 `:free` 后缀的模型免费 | `google/gemini-2.5-flash:free` | ✅ |

要点：

- 智谱申请：`open.bigmodel.cn` 注册（手机号）→ 个人中心 → API Keys；接口地址 `https://open.bigmodel.cn/api/paas/v4`，模型 `glm-4v-flash`，图片编码选「纯 base64」（选预设时会自动切好）。
- 做截图识题必须用 **支持图片输入** 的模型（名字带 `VL` / `vision` / `4v`）。
- 免费额度和模型名会变，以官网价格页为准；插件里模型名可随意改。

## 四、四种用法

| 方式 | 操作 | 适合 |
|---|---|---|
| **选中解题** | 划选题目文字 → 点浮出的「解题」气泡，或按 `Alt+Q` | 普通题库、网页文章里的题 |
| **点选取题** | 面板点「点选取题」→ 鼠标移到题目块出现绿框 → 点一下 | 结构化题库逐条刷 |
| **自动抓题** | 面板点「自动抓题」 | 排版规范的页面，自动找最像题目的文本块 |
| **截图识题** | 面板点「截图识题」→ 拖动框选区域 | 图片题、Canvas、PDF、iframe（需视觉模型） |

面板底部可切换 `只要答案 / 简要解析 / 详细解答`；答案可一键复制。快捷键 `Alt+Q` 可在 `edge://extensions/shortcuts` 修改。

## 五、常见问题

- **提示「免费接口限速 / FREE_LIMIT」**：免 Key 模式 45 秒 1 次，等一会儿或换自己的 Key。
- **报错 `1210 / max_tokens参数非法`**：该模型单次输出有硬上限（`glm-4v-flash` 只有 1024 tokens）。插件会自动按服务端给的上限重试一次；仍报错就把「最大输出长度」调到 1024 以下。想要长解析可换 `glm-4-flash` 或硅基流动的模型。
- **截图识题提示「当前接口不能读图」**：换 `glm-4v-flash` 这类视觉模型。
- **401 / 403**：Key 错、未实名、或没有该模型权限。
- **404**：接口地址或模型名错（地址填到 `/v1` 一层，不要带 `/chat/completions`）。
- **429**：免费额度或频率到上限，等一会儿或换服务商。
- **按钮不出现**：浏览器内置页 / 应用商店 / 新标签页不允许注入，换普通网页；老页面刷新一下。
- **插件的「设置」在哪**：面板右下角「设置」，或 `edge://extensions` 里点「扩展选项」。

## 六、文件结构

```
quiz-helper-extension/
├── manifest.json     # MV3 清单：权限、注入规则、快捷键
├── background.js     # Service Worker：配置、调用 API（流式 SSE）、截图、跨 frame 转发
├── content.js        # 页面内 UI：悬浮面板、选中气泡、点选/自动抓题、截图框选、Markdown 渲染
├── popup.html/js     # 工具栏弹窗：状态总览 + 打开面板
├── options.html/js   # 设置页：服务商预设、Key、模型、回答风格、测试连接
└── icons/            # 图标
```
